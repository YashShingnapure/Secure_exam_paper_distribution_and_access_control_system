# 🔐 Secure Exam Paper Distribution & Access Control System

## 📌 Overview

A secure web-based system designed to distribute exam papers digitally with strong encryption and time-based access control. This system ensures that exam papers are protected from unauthorized access and leakage.

---

## 🚀 Features

* 🔒 Secure PDF upload and encryption
* ⏳ Time-based exam paper unlocking
* 👥 Role-based access control (Admin, User)
* 🔐 User authentication with OTP verification
* 📊 Activity logging and monitoring

---

## 🛠️ Tech Stack

* **Backend:** Python (Flask)
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/YOUR-USERNAME/Secure_exam_paper_distribution_and_access_control_system.git
```

2. Navigate to project folder:

```
cd secure_exam_system
```

3. Create virtual environment:

```
python -m venv venv
```

4. Activate virtual environment:

* Windows:

```
venv\Scripts\activate
```

5. Install dependencies:

```
pip install -r requirements.txt
```

6. Run the application:

```
python app.py
```
